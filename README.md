# tmQM-RDF Knowledge Graph (v1.0.1)

This is the read only archive of the tmQM-RDF knowledge graph (v1.0.1).
For further details about the knowledge graph, see the [main repository](https://github.com/luca-cibinel/tmQM-RDF).

The knowledge graph can be easily downloaded and accessed via the Python package `tmqmrdfdata` ([see the package on PyPI (pypi.org)](https://pypi.org/project/tmqmrdfdata/)).
